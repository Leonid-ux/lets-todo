# Lets Todo

**Lets Todo** — минималистичное приложение для управления задачами, отслеживания привычек, событий и учёта времени. Поддерживает локальную синхронизацию между Windows и Android через Wi-Fi без облачных серверов.

## Возможности

- **Задачи** — создание задач и подзадач с датами, приоритетами, тегами и повторениями.
- **Умный ввод** — распознавание дат и времени из естественного языка. Например, «Встреча завтра в 15:00».
- **Привычки** — отслеживание ежедневных привычек, количества выполнений и истории прогресса.
- **Таймеры** — учёт времени с ручным запуском и остановкой.
- **События** — ведение календаря и регистрация событий.
- **Личные записи** — скрытые привычки, события и таймеры с возможностью защиты PIN-кодом.
- **Синхронизация** — обмен данными между устройствами через локальную сеть Wi-Fi, подключение по QR-коду или одноразовому коду, шифрование передаваемых данных.
- **Статистика** — просмотр активности и экспорт данных в JSON.
- **Уведомления** — системные уведомления и возможность сворачивания приложения в трей.
- **Обновления** — автоматическая проверка и установка новых версий Windows через GitHub Releases.

## Разработка

Для локального запуска проекта необходимы Node.js и npm.

```bash
git clone https://github.com/Leonid-ux/lets-todo.git
cd lets-todo
npm install
npm start
```
