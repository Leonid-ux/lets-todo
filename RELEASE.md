# Публикация Windows-версии

Автообновление использует GitHub Releases. Текст в поле **What’s changed** у релиза показывается пользователю в окне обновления.

## Первый выпуск 0.1.0

1. Создайте на GitHub пустой репозиторий и добавьте его как `origin`.
2. Закоммитьте проект и отправьте его в GitHub.
3. Создайте и отправьте тег версии:

   ```powershell
   git tag v0.1.0
   git push origin v0.1.0
   ```

GitHub Actions из `.github/workflows/release.yml` соберёт и создаст черновик/релиз с тремя нужными файлами:

- `Lets-Todo-Setup-0.1.0.exe`
- `Lets-Todo-Setup-0.1.0.exe.blockmap`
- `latest.yml`

Если вы предпочитаете создать релиз вручную, сначала соберите его локально:

```powershell
$env:UPDATE_REPOSITORY = 'ваш-логин/имя-репозитория'
npm run release:win
```

Затем прикрепите все три файла из папки `release` к одному GitHub Release с тегом `v0.1.0`. Репозиторий и релиз должны быть публичными, либо пользователю приложения понадобится доступ к приватному репозиторию.

## Следующая версия

Перед тегом измените `version` в `package.json` (например, на `0.1.1`) и обновите раздел в `CHANGELOG.md`. Тег всегда должен совпадать с версией: `v0.1.1` для версии `0.1.1`.
